# OM Ratio Report

Store generated OM Ratio reports and their supporting output datasets here.

Follow the complete, authoritative execution procedure in [REPORT_GENERATION_RUNBOOK.md](../REPORT_GENERATION_RUNBOOK.md). It documents data retrieval, percentiles, QB v2, OSA v2 field mappings, equal-weight trench composites, confidence, slate filters, spread handling, output naming, and verification.

Reports should identify the season, data retrieval date, eligible-game filters, model version, and confidence.
